Six rearing chambers run in a row, chamber 1 first, chamber 6 last. Mass is counted in whole nutrient units. Each chamber is LARVAL or PUPAL; all start LARVAL. Keep a loss tally from 0: everything discarded or metabolised goes on it.

Chambers 1 to 6:
Holding limit: 10, 8, 12, 6, 9, 7
Upper mark: 7, 6, 9, 5, 7, 5
Lower mark: 3, 2, 4, 2, 3, 2
Starting mass: 3, 6, 6, 2, 2, 1
Moult threshold, whole line: 38

Feed per cycle, chambers 1 to 6:
Cycle 1: 0, 6, 3, 5, 3, 3
Cycle 2: 4, 2, 0, 1, 1, 7
Cycle 3: 4, 4, 3, 0, 0, 6
Cycle 4: 7, 6, 7, 1, 3, 0
Cycle 5: 0, 6, 6, 3, 3, 0

Five cycles, five steps each, always in this order; finish each step on all six chambers before the next.

1. Feed. Add each chamber's table amount. No trimming; chambers may sit over limit.

2. Carry forward. Go chamber 1, 2, through 6. Anything above a chamber's limit moves into the next chamber, leaving it exactly at its limit. Chamber 1's excess reaches chamber 2 before chamber 2 is checked, so excess can cascade. Chamber 6's excess is discarded.

3. State check, on post-carry mass. LARVAL at or above its upper mark goes PUPAL. PUPAL at or below its lower mark returns to LARVAL, which is routine. Between marks, state holds. At most one change per chamber per cycle. Log each as (cycle, position, before, after).

4. Metabolism. First work out all six amounts from current contents, before changing any: LARVAL loses a quarter, PUPAL half, each rounded down. Then apply them together. LARVAL amounts are metabolised away. PUPAL amounts are reabsorbed into the previous chamber; chamber 1's, if PUPAL, is discarded. No limit applies here; overfull chambers are corrected only at the next cycle's carry forward, never after cycle 5.

5. Moult. Total the six chambers. Strictly above 38: every chamber keeps half, rounded down, the rest discarded; note the cycle. At 38 or below, nothing.

Report. After cycle 5, hand in: the six end quantities, positions 1 to 6; the six end states, same order; every state change as (cycle, position, before, after); the cycles the moult fired; the loss tally; and the balance check: starting quantities plus all feed must equal end quantities plus the loss tally.

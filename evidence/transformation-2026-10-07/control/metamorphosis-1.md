Six chambers in a row: chamber 1 at the head, 6 at the tail. Each holds a whole number of units of nutrient mass, never negative. All start LARVAL; loss tally starts at 0.

Chambers 1 to 6:
Capacity: 10, 8, 12, 6, 9, 7
Upper mark: 7, 6, 9, 5, 7, 5
Lower mark: 3, 2, 4, 2, 3, 2
Starting mass: 3, 6, 6, 2, 2, 1
Moult limit, whole line: 38

A run is five cycles, five steps each, in this order. Finish each step on all six before the next.

1. Feed. Add the cycle's ration from the feed table. Capacity ignored here.

2. Overflow. Walk 1 to 6. Anything over capacity moves into the next chamber, leaving it exactly at capacity. Chamber 1's excess reaches 2 before you check 2, so it cascades. Chamber 6's excess goes to the loss tally.

3. State check, on post-overflow mass. LARVAL at or above its upper mark goes PUPAL. PUPAL at or below its lower mark returns to LARVAL; that's routine. Between marks, state holds. At most one change per chamber per cycle; log each.

4. Metabolism. Work out all six amounts from mass at the start of this step before touching anything: LARVAL, a quarter; PUPAL, half; both rounded down. Apply together. Each chamber gives up its amount. LARVAL amounts are metabolised away to the loss tally. PUPAL amounts are reabsorbed into the chamber before it (4 sends to 3); chamber 1's PUPAL amount goes to the loss tally. No capacity check: an overfull chamber waits for next cycle's overflow; after cycle 5, it stays over.

5. Moult. If the six chambers total strictly more than 38, every chamber halves, rounded down; removed mass goes to the loss tally; note the cycle. At 38 or under, nothing.

Feed table, chambers 1 to 6:
Cycle 1: 0, 6, 3, 5, 3, 3
Cycle 2: 4, 2, 0, 1, 1, 7
Cycle 3: 4, 4, 3, 0, 0, 6
Cycle 4: 7, 6, 7, 1, 3, 0
Cycle 5: 0, 6, 6, 3, 3, 0

Report. After cycle 5, hand in: the six end masses in order 1 to 6; the six end states, same order; every state change as (cycle, chamber, before, after); the cycles the moult fired; the loss tally; and the balance check: starting total plus all feed must equal end total plus loss tally.

Six crucibles: 1 at the charging end, 6 at the tapping end. Melt counts in whole units. All start BASE.

Crucibles 1 to 6:
Working volume: 10, 8, 12, 6, 9, 7
Upper mark: 7, 6, 9, 5, 7, 5
Lower mark: 3, 2, 4, 2, 3, 2
Starting melt: 3, 6, 6, 2, 2, 1
Line limit (all six): 38

Charges, crucibles 1 to 6:
Cycle 1: 0, 6, 3, 5, 3, 3
Cycle 2: 4, 2, 0, 1, 1, 7
Cycle 3: 4, 4, 3, 0, 0, 6
Cycle 4: 7, 6, 7, 1, 3, 0
Cycle 5: 0, 6, 6, 3, 3, 0

Five cycles, five steps each, in order. Finish each step on all six before the next.

1. Charge. Add the cycle's charge to each crucible. Volume isn't enforced; overfull is allowed.

2. Overflow. Work 1 to 6, one at a time. Anything above working volume runs down the launder into the next crucible, leaving this one exactly full. What comes from 1 lands in 2 before you check 2, so overflow can carry down the line. Overflow from 6 goes to the slag pit.

3. Temperature check, on contents after overflow. BASE at or above the upper mark goes SUPERHEATED. SUPERHEATED at or below the lower mark goes BASE. Between the marks, no change. At most one change per crucible per cycle. Log each as (cycle, position, before, after).

4. Tap. Work out all six amounts first, from current contents, rounded down: BASE gives a quarter, SUPERHEATED half. Then move them together. BASE melt goes to slag. SUPERHEATED melt runs up the return launder into the crucible before it; from crucible 1, to slag. Volume isn't enforced: overfill only runs off at the next cycle's overflow, so after cycle 5 it stays.

5. Emergency tap. Total all six. Over 38 (exactly 38 doesn't count), every crucible keeps half, rounded down; the rest goes to slag. Note the cycle.

Slag tally starts at zero: overflow from 6, BASE taps, crucible 1's SUPERHEATED tap, emergency taps.

Report. At the end of cycle 5, hand in: the six end quantities, positions 1 to 6; the six end states, same order; every state change as (cycle, position, before, after); the cycles the emergency tap fired; the slag tally; and the balance check: starting melt plus all charges must equal end melt plus slag tally.

Six positions in a line, numbered 1 (upstream) to 6 (downstream). Each position holds a whole-number amount, never negative, and has a fixed capacity, an upper trigger and a lower trigger (lower < upper <= capacity), and one of two states, resting or raised. All positions start in the resting state. There is one global limit and one running loss tally that starts at 0. The run lasts exactly 5 rounds; each round has five steps in a fixed order, and each step is completed for all six positions before the next step begins.
Step 1: each position's amount rises by that round's entry in the input table. Capacity is not enforced; an amount may exceed capacity.
Step 2: positions are handled one at a time in order 1 to 6. If a position's amount is above capacity, the excess (amount minus capacity) is added to the next position downstream and the position is set to exactly its capacity; excess from position 6 is added to the loss tally. Because handling is in order, excess reaching a position arrives before that position is handled, so excess can cascade down the line in the same step.
Step 3: using amounts after step 2, a resting position whose amount is >= its upper trigger becomes raised; a raised position whose amount is <= its lower trigger becomes resting; otherwise the state is unchanged (a position between the triggers keeps its state). Each change is recorded as (round, position, old state, new state). At most one change per position per round.
Step 4: first compute every position's amount to move from its amount at the start of this step: resting = floor(amount / 4), raised = floor(amount / 2); all six computed before anything changes. Then apply all at once: every position decreases by its own amount; a resting position's amount goes to the loss tally; a raised position's amount is added to the position immediately upstream (n-1), and a raised position 1's amount goes to the loss tally. Capacity is not enforced; a position may end above capacity, corrected only at the next round's step 2, and never if this happens in round 5.
Step 5: sum all six amounts. If the total is strictly greater than the global limit, every amount becomes floor(amount / 2), everything removed is added to the loss tally, and the round is recorded as a reset round. If the total equals or is below the limit, nothing happens.
Output after round 5: each position's final amount in order 1 to 6; each final state in order 1 to 6; the full list of state changes as (round, position, old, new); the rounds in which a reset happened; the final loss tally; and the balance check: sum of starting amounts + sum of all inputs = sum of final amounts + loss tally.

Input table (rows rounds 1-5, columns positions 1-6): round 1: 0, 6, 3, 5, 3, 3; round 2: 4, 2, 0, 1, 1, 7; round 3: 4, 4, 3, 0, 0, 6; round 4: 7, 6, 7, 1, 3, 0; round 5: 0, 6, 6, 3, 3, 0.

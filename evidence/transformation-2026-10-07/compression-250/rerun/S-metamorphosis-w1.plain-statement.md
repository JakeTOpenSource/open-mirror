Mode: explanation mode (step 1, plain statement). Six cells in a line, numbered 1 (upstream) to 6 (downstream). Each cell has a whole-number level that is never negative, a fixed capacity C, an upper trigger U and a lower trigger D with D < U <= C, and a mode, NORMAL or ELEVATED. All cells start NORMAL. There is one global limit G and a running tally LOST that starts at 0. The process runs exactly 5 periods. Each period has five steps in a fixed order, and each step finishes for all cells before the next step starts. Step 1, intake: each cell's level rises by that period's intake for that cell, from the intake table; capacity is not enforced, so a level may exceed capacity. Step 2, spill-over: cells are handled one at a time in the order 1, 2, 3, 4, 5, 6. If a handled cell's level is above its capacity, the excess (level minus capacity) is added to cell n+1 and the cell's level becomes exactly its capacity; cell 6's excess is added to LOST. Because of the order, excess from one cell arrives in the next before that cell is handled, so overflows can cascade down the line in the same step. Step 3, mode check, on levels after spill-over: a NORMAL cell with level >= U becomes ELEVATED; an ELEVATED cell with level <= D becomes NORMAL; otherwise the mode is unchanged (in particular, a level between D and U keeps the current mode). Every change is recorded as (period, cell, old mode, new mode); a cell changes at most once per period. Step 4, release: first compute every cell's release from its level at the start of this step (NORMAL: floor(level/4); ELEVATED: floor(level/2)), all six before anything changes; then apply all at once: each cell's level drops by its own release; a NORMAL cell's release goes to LOST; an ELEVATED cell's release is added to cell n-1, except that an ELEVATED cell 1's release goes to LOST. Capacity is not enforced here; a cell may exceed capacity after receiving a transfer, and that is corrected only at the next period's spill-over (never, if it happens in period 5). Step 5, global reset: sum the six levels; if the total is strictly greater than G, every level becomes floor(level/2), every removed amount goes to LOST, and the period is recorded as a reset period; if the total is equal to G or less, nothing happens. Output after period 5: each cell's final level in order 1 to 6; each cell's final mode in order 1 to 6; the complete list of mode changes as (period, cell, old mode, new mode); the list of periods with a global reset; the final LOST; and the balance check: (sum of starting levels) + (sum of all intake amounts) = (sum of final levels) + LOST. Data: capacity C, cells 1 to 6: 10, 8, 12, 6, 9, 7. Upper trigger U: 7, 6, 9, 5, 7, 5. Lower trigger D: 3, 2, 4, 2, 3, 2. Starting level: 3, 6, 6, 2, 2, 1. Global limit G: 38. Intake table (rows periods 1 to 5, columns cells 1 to 6): period 1: 0, 6, 3, 5, 3, 3; period 2: 4, 2, 0, 1, 1, 7; period 3: 4, 4, 3, 0, 0, 6; period 4: 7, 6, 7, 1, 3, 0; period 5: 0, 6, 6, 3, 3, 0.
